Hakoniwa User Guide

Hakoniwa is an independent desktop app for supervising AI development tasks. The D1 build focuses on a clean path from Local Agent Gateway configuration to task monitoring.

Quick Start

Requirements: Node.js, npm, and a running Local Agent Gateway.

npm install
npm run dev

The app opens as a Hakoniwa desktop window. The development command builds a local release/mac-arm64/Hakoniwa.app shell, starts the Vite renderer, and launches that app through macOS LaunchServices with a --hakoniwa-dev-server-url argument.

Use the Hakoniwa window for Gateway settings and task creation. The browser preview at http://127.0.0.1:5173 is only for renderer layout checks because it cannot access the Electron preload bridge.

Local Agent Gateway

Hakoniwa treats Local Agent Gateway as an Agent Backend Provider. The default Gateway URL is: 

http://127.0.0.1:8787
  1. Enter the Gateway URL.
  2. Enter the Gateway token if required.
  3. Keep Prefer SSE events enabled unless unsupported.
  4. Click Save.
  5. Click Health check.
LOCAL_AGENT_GATEWAY_URL=http://127.0.0.1:8787 LOCAL_AGENT_GATEWAY_TOKEN=... npm run dev

Legacy CODEX_GATEWAY_URL and CODEX_GATEWAY_TOKEN are still accepted as fallbacks.

Secrets stay in the Electron main process credential vault. Gateway tokens are encrypted with Electron safeStorage and stored under the app user-data directory, with session-memory fallback only when OS encryption is unavailable. If the Gateway URL changes without a new token, Hakoniwa clears the previous token.

Load Repositories

After health check succeeds, Hakoniwa loads repo targets from:

GET /v1/repos

The left panel shows repo display name, default mode, allowed modes, provider, and connection status. D1 does not display or send raw absolute worktree paths.

Create A Task

  1. Select a repository.
  2. Choose read-only or workspace-write.
  3. Enter a prompt.
  4. Click Create task.
{
  "repo": "repo-id",
  "prompt": "task prompt",
  "mode": "read-only"
}

Monitor A Task

Task detail shows prompt, provider, repo, mode, status, agent response when reported by the Gateway, summary, changed files, timeline, and error state.

Hakoniwa prefers GET /v1/tasks/:id/events. Gateway agent.message.completed events are shown in the Agent Response panel and timeline. If the event endpoint closes after replaying current events, Hakoniwa reconnects with Last-Event-ID. If events are unavailable or fail, Hakoniwa polls GET /v1/tasks/:id.

Current Limits

  • approval center
  • OpenCode provider

Troubleshooting

Gateway URL not configured
Use http://127.0.0.1:8787 or your actual Gateway URL.
Unauthorized
Re-enter the Gateway token.
No repos returned
Confirm Local Agent Gateway supports GET /v1/repos.
Task timeline stops
Reload the app and run a health check again.
