Hakoniwa User Guide

Hakoniwa is an independent desktop app for supervising AI development tasks. The D1 build focuses on a clean path from Codex Gateway configuration to task monitoring.

Quick Start

Requirements: Node.js, npm, and a running Codex Gateway.

npm install
npm run dev

The app opens as a Hakoniwa desktop window. The development command builds a local release/mac-arm64/Hakoniwa.app shell, starts the Vite renderer, and launches that app with VITE_DEV_SERVER_URL.

Use the Hakoniwa window for Gateway settings and task creation. The browser preview at http://127.0.0.1:5173 is only for renderer layout checks because it cannot access the Electron preload bridge.

Codex Gateway

Hakoniwa treats Codex Gateway as an Agent Backend Provider. The default Gateway URL is: 

http://127.0.0.1:8787
  1. Enter the Gateway URL.
  2. Enter the Gateway token if required.
  3. Keep Prefer SSE events enabled unless unsupported.
  4. Click Save.
  5. Click Health check.
CODEX_GATEWAY_URL=http://127.0.0.1:8787 CODEX_GATEWAY_TOKEN=... npm run dev

Secrets stay in Electron main process session memory. If the Gateway URL changes without a new token, Hakoniwa clears the previous token.

Load Repositories

After health check succeeds, Hakoniwa loads repo targets from:

GET /v1/repos

The left panel shows repo display name, default mode, allowed modes, provider, and connection status. D1 does not display or send raw absolute worktree paths.

Create A Task

  1. Select a repository.
  2. Choose read-only or workspace-write.
  3. Enter a prompt.
  4. Click Create task.
{
  "repo": "repo-id",
  "prompt": "task prompt",
  "mode": "read-only"
}

Monitor A Task

Task detail shows prompt, provider, repo, mode, status, summary, changed files, timeline, and error state.

Hakoniwa prefers GET /v1/tasks/:id/events. If events are unavailable, fail, or close before the task reaches a terminal state, Hakoniwa polls GET /v1/tasks/:id.

Current Limits

  • managed worktrees
  • full terminal
  • full browser preview
  • full diff viewer
  • approval center
  • OpenCode provider
  • Direct API Agent
  • direct model provider execution

Troubleshooting

Gateway URL not configured
Use http://127.0.0.1:8787 or your actual Gateway URL.
Unauthorized
Re-enter the Gateway token.
No repos returned
Confirm Codex Gateway supports GET /v1/repos.
Task timeline stops
Reload the app and run a health check again.
