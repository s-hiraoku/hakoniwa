# Goal Manager Examples

Use these examples to turn informal requests into concrete objectives.

## Bug Fix

User request:

> Fix the failing login redirect.

Objective:

> Reproduce and fix the login redirect failure, add focused regression coverage where practical, run relevant verification, and summarize the fix and remaining risks.

## Feature Implementation

User request:

> Add export support.

Objective:

> Implement export support for the requested surface, update tests and docs for the new behavior, run targeted and repository-level verification, and summarize changed files and risks.

## PR Review Comments

User request:

> Address the unresolved PR comments.

Objective:

> Inspect unresolved PR review feedback, implement the requested fixes, run targeted verification, and summarize addressed comments plus any remaining blockers.

## Release Check

User request:

> Check whether this is ready to release.

Objective:

> Review the current diff for release readiness, run relevant checks, identify blocking risks, and summarize release status with required follow-up work.

## Documentation Update

User request:

> Update the docs for this change.

Objective:

> Update the relevant documentation for the changed behavior, verify links or docs checks where available, and summarize docs touched plus any stale areas found.

## PR Creation

User request:

> Use /goal and create a PR.

Objective:

> Implement the requested change, update tests and documentation where needed, run repository verification, commit and push a focused branch, open a draft PR, and summarize the PR URL with validation results and risks.
